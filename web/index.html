Watchtower: what does a release change?

Drop a package and it is compared with the version before it. It looks only at what is new: install scripts, credential reads, network calls, obfuscated blobs, new executables. Everything runs in your browser; nothing is uploaded.

With a package name below, the earlier version is fetched from the npm registry for you.
